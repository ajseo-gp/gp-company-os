# Production

**Status:** REVIEW
**Version:** 0.2

## Purpose

확정된 레시피와 발주 사양을 추적 가능한 생산 LOT로 전환하고, 제조·검수·출고 기록을
일관되게 남긴다.

## Production Scope

- 샴푸
- 두피 스케일링 제품
- 두피 토닉 및 미스트형 제품
- 바디워시·핸드워시
- 스프레이형 트리트먼트
- 기타 제형은 설비와 처방 가능성을 확인한 후 결정

## Production Control Points

1. 확정 레시피, 발주 사양과 생산수량 대조
2. 생산 LOT 생성과 레시피·고객·스케쥴 연결
3. 처방 및 원료 준비
4. 부자재 입고·수량 확인
5. 제조 일정과 설비 확정
6. 제조·충진·포장
7. 실측 pH, 외관, 수량과 표시사항 검수
8. 생산완료·출고 상태 기록
9. 생산·품질 문서와 원본 근거 보관

## State Flow

```text
레시피 확정
→ 샘플·수주 확인
→ 생산 예정
→ LOT 생성
→ 제조·충진·포장
→ 생산 완료
→ 출고
```

- 연구중 레시피로 생산 LOT를 만들지 않는다.
- LOT는 연결된 레시피, 발주처, 수량, 배치와 제조일을 추적할 수 있어야 한다.
- 생산 시작 후 레시피 변경은 기존 기록을 덮어쓰지 않고 승인된 변경 기록으로 남긴다.
- 제품별 시험 근거가 확인되지 않으면 COA나 대외 품질 문구를 일반화하지 않는다.
- 기능성 여부, 효능·효과, 사용기한, 시험결과와 부자재 공급조건을 템플릿 기본값만으로
  확정하지 않는다.

## Required Data

- 연결 레시피와 확정 revision
- 고객사·발주번호·발주일·제조일
- LOT 번호와 생산 상태
- 배치 용량과 생산 가능 수량
- 원료 소요량과 원가
- 용기·펌프·캡·라벨·단상자 단가
- 제조·충진·포장 작업시간
- 예상 로스율
- 불량 및 재작업 기록
- 생산 리드타임
- 설비와 실측 pH
- 검수·시험 결과와 근거 문서

## Production Outputs

- 생산기록일지
- 제조기록서
- 제품표준서
- 품질검사성적서(COA)
- 제품별 안전·취급 문서

Workbench에서 문서를 자동 산출하더라도 제품별 사실, 시험 결과, 법적 적합성과 발행 권한을
별도로 확인한다.

## Data Boundary

- 실제 처방·함량, 원가, 고객정보와 시험성적서 원본은 공개 저장소에 기록하지 않는다.
- Workbench는 실행 기록과 연결 식별자를 관리하고 Company OS는 정책을 관리한다.
- 실제 발행 문서와 원본자료는 승인된 보안 저장소의 고객·제품별 경로에 보관한다.
- 운영 데이터 변경·복원 전 백업과 rollback 방법을 확인한다.

## Rule

확정되지 않은 생산 가능 범위, 원료 효능, 납기는 고객에게 단정하지 않는다.

## Unconfirmed Items

- 연구실 생산과 외부 ISO/CGMP 생산의 공식 구분
- 제품 유형별 필수 시험과 합격 기준
- COA·MSDS 발행 책임자와 승인 절차
- 표준 LOT 번호와 문서 보존기간
- 표준 작업시간, 로스율과 불량·재작업 처리 기준
- 실제 생산 시작 승인 권한
