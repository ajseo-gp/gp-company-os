# Research & Development

**Status:** REVIEW

**Version:** 0.1

## Purpose

Hair·Scalp 제품의 고객 요구를 검증 가능한 연구 조건과 레시피로 전환하고, 확정된 결과만
견적·샘플·생산으로 넘긴다.

## Scope

- 고객 문의와 개발 요구의 연구 조건화
- 자사 브랜드와 고객사 제품의 레시피 연구
- 원료, 함량, 투입상, 핵심·컨셉 원료와 제조 방식 관리
- 목표 pH·점도·향·원가·완료일과 제한조건 관리
- 연구원 내부 피드백과 고객용 설명 분리
- 연구중 레시피의 확정, 확정 취소와 후속 견적·생산 연결

의약적 효능 확정, MFDS 법률 판단, 검증되지 않은 원료 효능 단정과 실제 배합 원문의
공개 저장소 기록은 이 문서의 범위가 아니다.

## Operating Model

```text
고객 문의·자사 제품 요구
→ 연구 조건
→ 원료·레시피 작성
→ 연구중 저장·실험
→ 레시피 확정
→ 정밀 견적·샘플
→ 수주 확정
→ 생산 스케쥴·LOT·생산 문서
```

## Research Brief

연구 시작 전 가능한 범위에서 다음 조건을 기록한다.

- 연구 대상: 자사 브랜드 / 고객사 / 미분류
- 제품 유형, 제품명과 용량
- 목표·컨셉
- 목표 pH와 점도
- 향 방향과 벤치마크 제품
- 금지·제한 원료 또는 규제 조건
- 목표 원가와 완료 희망일
- 연결된 고객 문의와 당시 요구사항 요약

확인되지 않은 값은 추정해 채우지 않고 `확인 필요`로 남긴다.

## Recipe State

| 상태 | 의미 | 허용되는 다음 행동 |
|---|---|---|
| 연구중 | 실험·수정 가능한 작업본 | 저장, 수정, 검토, 확정 요청 |
| 확정 | 견적과 생산 준비에 사용할 수 있는 승인된 레시피 | 정밀 견적, 샘플, 수주·생산 연결 |

- 연구중 저장만으로 생산 스케쥴을 생성하지 않는다.
- 확정 시 함량 합계, 필수 연구 조건, 원료 마스터 연결과 승인자를 확인한다.
- 수주 또는 생산 LOT가 연결된 확정 레시피는 단순 확정 취소하지 않는다.
- 확정·확정 취소·수주 확정은 수행자와 시각을 남긴다.

## Outputs

- 연구 조건과 연결 근거
- 레시피와 원료 구성
- 연구원 내부 피드백
- 고객용 제품 설명
- 수량 구간별 참고 원가
- 확정 상태와 변경 이력
- 견적·스케쥴·LOT 연결 식별자

참고 원가는 견적이 아니다. 고객 발송 가격은 원가, 부자재, 작업, 개발, 배송과 승인된
마진·결제조건을 반영한 정밀 견적 절차를 거친다.

## Data Boundary

- 실제 처방·함량, 원료 단가와 고객정보는 공개 OS·Hub 저장소에 기록하지 않는다.
- Company OS는 정책과 상태 전환 원칙의 원본이다.
- GP Workbench는 연구·견적·생산 실행 기록을 관리한다.
- 실제 발행 문서와 고객별 원본자료의 위치는 승인된 보안 저장소 기준을 따른다.
- Slack, PR, Preview와 스크린샷에 실제 처방·원가·고객정보를 노출하지 않는다.

## Required Management Views

- 연구중 / 확정 레시피와 지연 건
- 문의에서 연구 조건으로 연결된 비율
- 연구 시작부터 확정까지의 리드타임
- 샘플 조정 횟수와 주요 변경 사유
- 확정 레시피의 견적·수주·LOT 연결 상태
- 목표 원가 대비 참고 원가와 확인 필요 원료

## Unconfirmed Items

- 레시피 확정 권한과 대리 승인 범위
- 필수 시험·검사와 제품 유형별 합격 기준
- 샘플 개발비, 조정 횟수와 환급·공제 기준
- 연구 데이터의 장기 저장소와 보존기간
- 연구 실패·중단·폐기 기준
- 제품별 목표 원가와 수익성 기준

위 항목은 CEO와 연구 책임자가 확정한 Decision에 따라 ACTIVE 기준으로 전환한다.
