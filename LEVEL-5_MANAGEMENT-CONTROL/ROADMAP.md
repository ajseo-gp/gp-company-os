# GP Company OS Roadmap

## Phase 1 — Foundation

- 5-Level 문서 구조 구축
- 기존 회사 자료 수집·분류
- 핵심 Decision과 Context 확정
- OEM·견적·콘텐츠 SOP 작성

## Phase 2 — Standardization

- 원가·MOQ·마진 데이터 정리
- OEM Pipeline 표준화
- Prompt Library 검증
- Weekly Review 정착

## Phase 3 — Automation

- 문의 자동분류
- 후속 연락 자동화
- KPI 자동집계
- 콘텐츠 초안 자동생성

## Phase 4 — Management System

- CEO Dashboard 구축
- 제품·프로젝트별 손익 연결
- Agent 성과와 오류 모니터링
- 분기별 OS 개선
