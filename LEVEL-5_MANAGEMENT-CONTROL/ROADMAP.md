# GP Company OS Roadmap

## Phase 1 — Foundation

- 5-Level 문서 구조 구축
- 기존 회사 자료 수집·분류
- 핵심 Decision과 Context 확정
- OEM·견적·콘텐츠 SOP 작성
- Hair·Scalp와 AI·Company OS 이중 수익 엔진 확정
- `gp-company-os`의 최상위 원본 지위 확정

## Phase 2 — Standardization

- 원가·MOQ·마진 데이터 정리
- OEM Pipeline 표준화
- 문의→연구→견적→스케쥴→LOT 상태와 원본 경계 표준화
- OS·Hub·Workbench의 R&D·생산 정의와 적용 OS revision 정렬
- Prompt Library 검증
- Weekly Review 정착
- B2C Growth Operator와 실행 Agent 역할 정의
- Workbench Closed Beta 개발을 `gpwb_bot`·로컬 Claude Code Fast Lane으로 분리
- 두 수익 엔진의 분리 손익과 KPI 정의
- 하위 저장소의 OS 버전 추적 규약 정의

## Phase 3 — Automation

- 문의 자동분류
- 후속 연락 자동화
- KPI 자동집계
- 콘텐츠 초안 자동생성
- B2C 전략→캠페인→실행→피드백 Workflow 구축
- GP Workbench 작업 큐·승인함·로그 구축
- Hermes 자연어 접수와 Task-ID·OS-Ref 자동 생성
- 내부 AI·OS 적용 전후 효과 측정

## Phase 4 — Management System

- CEO Dashboard 구축
- 제품·프로젝트별 손익 연결
- Agent 성과와 오류 모니터링
- 분기별 OS 개선
- 대표 의존도와 자산 소유권 관리

## Phase 5 — AI & Company OS Commercialization

- 내부 검증 사례 선정과 증거 패키지 작성
- 외부 고객 문제와 상품 후보 검증
- 구축형 서비스의 범위와 계약 기준 확정
- 반복 가능한 Workbench·Agent 기능 분리
- 외부 고객 도입, 성과, 유지와 반복매출 측정

## Phase 6 — Transferable Company

- 대표 없이 실행 가능한 핵심 Workflow 검증
- 수익 엔진별 재무·고객·운영 기록 정리
- 브랜드·코드·계약·데이터 권리와 접근권한 정리
- 경영 인수 문서와 운영 데이터룸 유지
- 전체 회사 또는 사업부 단위의 투자·매각 선택권 확보
