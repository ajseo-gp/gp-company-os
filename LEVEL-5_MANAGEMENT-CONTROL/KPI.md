# KPI Framework

| 영역 | 핵심 KPI | 목적 |
|---|---|---|
| OEM | 문의 수, 응답시간, 견적률, 계약률, 평균 계약액 | B2B 매출 전환 |
| B2C | 매출, 전환율, 객단가, 재구매율, 기여이익 | 브랜드 성장 |
| Production | 리드타임, 불량률, 로스율, 납기 준수율 | 생산 안정성 |
| Marketing | 콘텐츠 수, 유입, 문의, 구매기여 | 마케팅 효율 |
| Finance | 현금잔고, 미수금, 총이익률, 고정비 커버 | 생존과 수익성 |
| AI | 자동화 건수, 절감시간, 승인수정률, 오류율 | OS 생산성 |

## Rule

정의와 데이터 원천이 없는 숫자는 KPI로 사용하지 않는다.
