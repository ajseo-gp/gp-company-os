# Prompt: 브랜드 콘텐츠 기획

GP Company 또는 젠틀파파의 실제 제품·브랜드 정보를 사용한다. 치료, 의학적 효능, 탈모 치료 등 오해 가능한 표현을 피한다.

## 입력

- 브랜드: {{BRAND}}
- 제품/서비스: {{PRODUCT}}
- 채널: {{CHANNEL}}
- 목표: {{OBJECTIVE}}
- 대상: {{AUDIENCE}}
- 근거 자료: {{FACTS}}

## 출력

1. 핵심 메시지
2. 0~3초 훅
3. 전체 구성
4. 본문 또는 시나리오
5. CTA
6. 사용 금지 표현 검토
7. 성과 측정 지표
