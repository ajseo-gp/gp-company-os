# SOP-010 연구에서 생산까지

**Status:** REVIEW

**Version:** 0.1

**Owner:** CEO / Research / Production

**변경일:** 2026-07-23

## 목적

고객 문의 또는 자사 제품 요구를 연구 조건과 레시피로 전환하고, 확정된 결과만 견적·수주·
생산으로 연결해 처방 오류, 중복 스케쥴과 추적 불가능한 생산을 방지한다.

## 적용 범위

- GP Workbench의 문의, 원료, 레시피 연구, 정밀 견적, 생산 스케쥴과 생산 문서
- Hair·Scalp B2B OEM/ODM과 자사 브랜드 제품 연구

실제 고객정보, 원가와 처방 원문의 공개 저장소 이동에는 적용하지 않는다.

## 필수 입력

- 연구 대상과 제품명·유형·용량
- 고객 문의 또는 자사 제품 요구
- 목표·컨셉과 완료 희망일
- 확인 가능한 pH·점도·향·벤치마크·제한조건
- 원료 마스터와 레시피 함량
- 연구원 피드백
- 고객용 설명

## 실행 단계

### 1. 연구 접수

1. 기존 문의와 연결하거나 자사 제품 요구로 시작한다.
2. 연구 대상을 자사 브랜드, 고객사 또는 미분류로 기록한다.
3. 문의가 연결되면 당시 요구사항 요약을 레시피에 남긴다.
4. 확인되지 않은 조건은 추정하지 않고 확인 필요로 표시한다.

### 2. 연구중 레시피 작성

1. 제품 유형, 용량과 제조 방식을 입력한다.
2. 원료 마스터에서 원료를 선택하고 함량과 투입상을 기록한다.
3. 공유·전용 원료와 핵심·컨셉 원료를 구분한다.
4. 연구원 내부 피드백과 고객용 설명을 분리한다.
5. `연구중`으로 저장한다.
6. 연구중 저장만으로 견적 확정이나 생산 스케쥴을 생성하지 않는다.

### 3. 확정 검토

1. 함량 합계가 100%인지 확인한다.
2. 누락 또는 미확정 원료와 단가를 확인한다.
3. 목표 pH·점도·향·제한조건과 연구 결과를 대조한다.
4. 생산 가능 범위와 제조 방식을 확인한다.
5. 연구 책임자의 확정 권한을 확인한다.

### 4. 레시피 확정

1. 레시피 상태를 `확정`으로 전환한다.
2. 수행자와 확정 시각을 기록한다.
3. 같은 `recipeId`로 열린 스케쥴이 없는 경우에만 한 건을 생성한다.
4. 생성한 스케쥴의 연구 단계는 완료 처리한다.
5. 확정 레시피를 정밀 견적에서 선택 가능하게 한다.

### 5. 정밀 견적과 수주

1. 확정 레시피, 원료와 생산수량을 불러온다.
2. 부자재, 작업, 개발, 배송, 로스와 승인된 마진을 확인한다.
3. 참고 원가와 고객 발송 견적을 구분한다.
4. 고객 발송 전 가격·결제·납기·법적 표현에 필요한 승인을 받는다.
5. 수주 확정 시 기존 `recipeId` 스케쥴을 갱신하고 수행자·시각을 기록한다.

### 6. 샘플·생산·출고

1. 스케쥴을 연구→샘플→생산→출고 단계로 관리한다.
2. 생산 전 확정 레시피와 발주 사양이 일치하는지 확인한다.
3. 생산 LOT를 생성하고 `recipeId`를 연결한다.
4. LOT와 레시피·원료를 기반으로 필요한 생산 문서를 산출한다.
5. 시험결과, 기능성 여부, 사용기한, 효능·효과와 부자재 공급조건은 제품별 근거를 확인한다.
6. 실측값, 검수 결과, 생산완료와 출고 상태를 기록한다.

## 확정 취소

- 수주와 생산 LOT가 없을 때만 연구중으로 되돌릴 수 있다.
- 확정 취소 시 수행자·시각을 기록하고 자동 생성된 열린 스케쥴을 정리한다.
- 수주 또는 LOT가 연결됐으면 취소를 차단하고 연결 해제·정정 절차를 별도 승인받는다.
- 기존 운영 기록을 삭제해 상태를 맞추지 않는다.
- 다른 레시피·견적·스케쥴·LOT가 참조하는 원료와 운영 기록을 하드 삭제하지 않는다.

## 승인 지점

- 레시피 확정과 확정 취소 권한
- 고객 발송 가격·결제조건·납기
- 실제 생산 시작과 처방 변경
- 제품별 시험·검사 결과와 COA 발행
- 실제 고객·처방·원가 데이터의 이동·삭제·복원

## 출력물

- 연구 조건과 레시피
- 연구원 피드백과 고객용 설명
- 확정·확정 취소 감사기록
- 정밀 견적과 수주 연결
- 단계별 생산 스케쥴
- LOT와 생산 문서

## 실패·예외 처리

| 조건 | 처리 |
|---|---|
| 원료 마스터 누락 | 확정 중단, 원료 등록·검증 후 재시도 |
| 함량 합계 불일치 | 확정 중단 |
| 중복 확정 요청 | 기존 스케쥴 반환, 새 카드 생성 금지 |
| 수주·LOT 연결 후 확정 취소 | 차단하고 정정 승인 요청 |
| 연결된 원료·레시피·스케쥴·LOT 삭제 | 하드 삭제 차단, 참조 현황과 보존·정정 방법 검토 |
| 레시피와 LOT 사양 불일치 | 생산 시작 중단, 책임자 검토 |
| 데이터 저장·백업 실패 | 쓰기 중단, 원본 보존과 복구 상태 보고 |
| 시험 근거 범위 불명확 | COA·대외 문서 발행 중단, 품질·대표 검토 |
| 생산문서에 제품별 근거 없는 고정 결과·조건 존재 | 자동 확정·발행 금지, 실제 근거로 교체 후 승인 |
