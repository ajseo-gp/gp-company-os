# SOP Library

SOP는 반복 업무를 동일한 품질로 수행하기 위한 표준 절차다.

## SOP Required Fields

- 목적
- 적용 범위
- 입력 정보
- 실행 단계
- 승인 필요 지점
- 출력물
- 실패·예외 처리
- 관련 Decision/Knowledge/Prompt
- 담당자 또는 Agent
- 버전과 변경일
