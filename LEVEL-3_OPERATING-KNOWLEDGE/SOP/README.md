# SOP Library

SOP는 반복 업무를 동일한 품질로 수행하기 위한 표준 절차다.

## Workflow와의 경계

- Workflow는 여러 역할·시스템이 시작부터 결과까지 이동하는 상태와 인계를 정의한다.
- SOP는 Workflow의 한 단계 또는 한 역할이 반복 수행하는 상세 절차를 정의한다.
- 동일한 실행 단계를 Workflow와 SOP에 복사하지 않는다. Workflow는 SOP ID를 참조한다.
- SOP가 바뀌어 상태·역할·승인 흐름이 달라지면 관련 Workflow도 함께 검토한다.

## SOP Required Fields

- 목적
- 적용 범위
- 입력 정보
- 실행 단계
- 승인 필요 지점
- 출력물
- 실패·예외 처리
- 관련 Decision/Knowledge/Prompt
- 담당자 또는 Agent
- 버전과 변경일

SOP는 최소 하나의 Workflow 또는 반복 운영 목적에 연결한다. `ACTIVE` SOP가 없는 단계는
자동화하지 않으며 임시 수동 절차로 표시한다.
