# DEC-0013 멀티채널 상품·가격·프로모션 자동화

- 상태: ACTIVE
- 결정일: 2026-07-28
- 적용일: 2026-07-28
- 결정자/소유자: GP Company CEO
- 적용 범위: 스마트스토어·쿠팡 및 승인된 쇼핑몰의 상품 등록·가격·프로모션 실행
- 대체하는 Decision: 없음
- 대체된 Decision: 없음

## 배경

젠틀파파 B2C의 매출 병목은 유입과 전환 실행 속도다. 채널별 상품 등록, 가격 설정과
프로모션을 대표가 손으로 반복하면 매출 확대 속도가 대표 시간에 묶인다. Claude Code가
채널별 API·자동화로 실행하되, 임의 가격이나 무제한 광고비가 아닌 승인된 상업 규칙 안에서
자동으로 운영해야 한다.

## 결정

Claude Code를 멀티채널 상거래 자동화의 단일 기술 실행자로 지정한다. 스마트스토어·쿠팡과
대표가 활성화한 다른 쇼핑몰의 credential은 분리된 secret store에서만 사용하며, 다음
실행 등급과 범위를 적용한다.

| 등급 | 대상 | 승인 |
|---|---|---|
| `L0` | 조회·분석·개선안·dry-run | 불필요 |
| `L1` | 해당 채널에 없는 상품의 신규 등록·카탈로그 동기화 | 채널별 첫 1건 대표 승인 후 자동 |
| `L2` | 판매 중 상품의 콘텐츠·옵션·이미지 변경 | 상업 규칙 안에서는 자동, 규칙 밖은 건별 승인 |
| `L3` | 가격 설정·가격 변경·할인·쿠폰·프로모션 | 상업 규칙 안에서는 자동, 규칙 밖은 건별 승인 |

1. `L1`은 승인된 카탈로그 revision을 활성 채널에 신규 등록하는 경우에 자동화한다.
   채널별 첫 1건은 대표 승인으로 등록·검증하며, 성공 후 같은 규칙 범위의 신규 등록은
   Claude Code가 자동 실행한다.
2. Claude Code는 상품명, 검색 키워드·태그, 상품 소개·상세페이지, 옵션명·속성,
   대표이미지 문구, 가격, 재고, 할인·쿠폰·번들·무료배송 등 채널 프로모션을 실행할 수 있다.
3. 가격·재고·프로모션 자동 실행은 활성 `Commerce Control Rules` 안에서만 허용한다.
   이 규칙에는 최소한 적용 채널·상품/SKU, 가격 하한·상한 또는 산식, 최대 할인율,
   프로모션 유형, 시작·종료 시각, 일·총 예산 또는 비용 상한, 중단 조건과 rollback
   방법이 포함되어야 한다. 규칙이 없거나 값을 벗어나면 Claude Code는 실행하지 않고
   대표 결정으로 올린다.
4. 유료 광고·외부 매체 집행도 동일 규칙에 채널·일·총 예산 상한이 명시된 경우에만
   자동 실행한다. 결제·환불·정산·계정·권한 변경은 계속 권한 밖이다.
5. 실행 전에는 화장품 표현 검수, 채널의 현재 필수 필드·길이·카테고리 규칙, SKU 매칭,
   변경 전 값 저장, 중복 등록 확인과 rollback 또는 판매중지 경로를 모두 통과해야 한다.
   하나라도 실패하면 외부 쓰기를 실행하지 않는다.
6. SKU가 없거나 채널 간 상품 동일성을 확인할 수 없는 상품은 자동화 대상에서 제외한다.
7. 모든 외부 변경은 Task-ID, 상품·SKU revision, 채널, 변경 전·후 값, 적용한
   Commerce Control Rules revision, 승인 상태,
   외부 상품 ID, 실행 시각·주체와 rollback 경로를 기록한다. credential과 고객·원가
   원문은 기록하지 않는다.
8. 채널별 `L1`·`L2`·`L3` 자동화는 실패·반려·예산 초과·규칙 이탈 1건이 발생하면 즉시
   중단한다. 재개에는 원인·
   rollback 결과와 재개 근거를 대표에게 보고해야 한다.
9. `externalWriteEnabled`는 이 Decision의 검사 Gate, 상업 규칙, 실행 기록과 중단 규칙이 구현·
   검증된 경우에만 활성화한다. 쓰기 함수만 먼저 만들고 Gate를 나중에 붙이지 않는다.

## 이유

신규 채널 등록, 가격 반응과 프로모션은 매출 유입·전환을 넓히는 직접 수단이다. 상업 규칙을
먼저 고정하면 대표는 가격·할인·예산을 매번 입력하지 않아도 되고, Claude Code는 그 범위
안에서 빠르게 실행·측정·중단할 수 있다.

## 영향 범위

### 적용

- 승인된 카탈로그→스마트스토어·쿠팡 및 활성 쇼핑몰의 신규 등록·콘텐츠·가격 동기화
- 채널별 할인·쿠폰·프로모션과 규칙 안의 유료 집행
- 쓰기 Adapter, 표현·SKU·필수필드 검사 Gate, 상업 규칙, rollback과 실행 기록
- B2C Growth의 상업 규칙·자동화 상태와 `externalWriteEnabled` 표시

### 비적용

- 활성 Commerce Control Rules가 없는 상품·채널·가격·프로모션
- 결제·환불·정산·계정·권한 변경, 규칙 밖의 예산 집행
- 고객 발송, 리뷰 조작, 계정 생성, 계약
- 사람이 지정하지 않은 채널·상품으로의 자동 확장

## 결과와 Trade-off

- 채널·상품·가격·프로모션 규칙을 한 번 설정하면 대표가 실행마다 중계하지 않아도 된다.
- 규칙 밖의 가격·예산 판단은 자동화하지 않아 수익성·현금 리스크를 통제한다.
- 실패·반려·예산 초과 1건에서 자동을 멈춰 잘못된 대량 실행을 차단한다.

## 전환과 검증

1. Claude Code가 스마트스토어·쿠팡과 활성 쇼핑몰 Adapter에 검사 Gate, Commerce Control
   Rules 검증, idempotency, rollback과 실행
   기록을 함께 구현한다.
2. 채널별 안전한 검증 범위에서 등록·가격 반영·프로모션·rollback을 확인한다.
3. 대표 승인으로 채널별 첫 `L1` 상품을 실행하고, 이후 규칙 안의 `L1`~`L3` 실행 결과를
   B2C Growth에 기록한다.
4. 성공 기준은 규칙 없는 외부 쓰기 0건, 표현 검수 미통과 반영 0건, 중복 등록 0건,
   예산 초과 0건, 실행 기록·rollback 경로 100%다.

## 재검토 조건

- 스마트스토어·쿠팡 또는 활성 쇼핑몰 API 정책·권한·인증 방식 변경
- 오등록, 중복 등록, 표현 반려, 예산 초과 또는 rollback 실패
- 새 쇼핑몰을 활성화하거나 상업 규칙의 가격·예산 기준을 변경하는 경우
