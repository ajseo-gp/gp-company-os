# DEC-0013 채널 상품 등록 자동화

- 상태: ACTIVE
- 결정일: 2026-07-28
- 적용일: 2026-07-28
- 결정자/소유자: GP Company CEO
- 적용 범위: 승인된 상품 카탈로그와 쿠팡 채널의 상품 정보 등록·수정
- 대체하는 Decision: 없음
- 대체된 Decision: 없음

## 배경

젠틀파파 B2C의 매출 병목은 유입 확대이며, 채널을 늘릴 때마다 대표가 상품을 손으로
등록하면 매출 확대 속도가 대표 시간에 묶인다. 현재 상품 조회 연결은 확인됐지만 쓰기
Adapter·검사 Gate·롤백 계약이 없어 Claude Code가 안전하게 등록을 실행할 수 없다.

## 결정

Claude Code를 채널 등록 자동화의 단일 기술 실행자로 지정한다. 카탈로그와 쿠팡의 key는
분리된 secret store에서만 사용하며, 다음 위험등급과 범위를 적용한다.

| 등급 | 대상 | 승인 |
|---|---|---|
| `L0` | 조회·분석·개선안·dry-run | 불필요 |
| `L1` | 해당 채널에 없는 상품의 신규 등록 | 채널별 첫 1건 대표 승인 후 자동 |
| `L2` | 판매 중 상품의 상품명·태그·상세 변경 | 건별 대표 승인 |

1. `L1`은 카탈로그의 승인된 상품 revision을 쿠팡에 신규 등록하는 경우에만 자동화한다.
   채널별 첫 1건은 대표 승인으로 등록·검증하며, 성공 후 같은 허용 범위의 신규 등록은
   Claude Code가 자동 실행한다.
2. 다음 필드만 등록·수정할 수 있다: 상품명, 검색 키워드·태그, 상품 소개·상세페이지,
   옵션명·속성, 대표이미지 문구. 신규 등록에 필요한 가격·재고는 승인된 카탈로그 값을
   그대로 전송할 수 있으나 Claude Code가 값을 선택·변경·할인 적용할 수 없다.
3. 가격, 할인, 재고 변경, 판매상태 변경, 광고·프로모션, 정산, 계정·권한 변경은
   이 Decision의 권한 밖이며 별도 Decision 없이는 실행하지 않는다.
4. 실행 전에는 화장품 표현 검수, 채널의 현재 필수 필드·길이·카테고리 규칙, SKU 매칭,
   변경 전 값 저장, 중복 등록 확인과 rollback 또는 판매중지 경로를 모두 통과해야 한다.
   하나라도 실패하면 외부 쓰기를 실행하지 않는다.
5. SKU가 없거나 채널 간 상품 동일성을 확인할 수 없는 상품은 자동화 대상에서 제외한다.
6. 모든 외부 변경은 Task-ID, 상품·SKU revision, 채널, 변경 전·후 값, 승인 상태,
   외부 상품 ID, 실행 시각·주체와 rollback 경로를 기록한다. credential과 고객·원가
   원문은 기록하지 않는다.
7. 채널별 `L1` 자동화는 실패 또는 반려 1건이 발생하면 즉시 중단한다. 재개에는 원인·
   rollback 결과와 재개 근거를 대표에게 보고해야 한다.
8. `externalWriteEnabled`는 이 Decision의 검사 Gate, 실행 기록과 중단 규칙이 구현·
   검증된 경우에만 활성화한다. 쓰기 함수만 먼저 만들고 Gate를 나중에 붙이지 않는다.

## 이유

신규 채널 등록은 매출 유입을 넓히는 직접 수단이다. 다만 자동화가 규제 표현이나 틀린
상품 정보를 더 빨리 확산시키면 브랜드·계정 위험이 커진다. 신규 등록은 첫 1건 검증 후
자동화하고, 기존 판매 상품의 변경은 건별 승인으로 분리해 속도와 통제를 함께 확보한다.

## 영향 범위

### 적용

- 승인된 상품 카탈로그→쿠팡 신규 등록과 허용 필드 동기화
- 쓰기 Adapter, 표현·SKU·필수필드 검사 Gate, rollback과 실행 기록
- B2C Growth의 채널 등록 승인 카드와 `externalWriteEnabled` 상태

### 비적용

- 스마트스토어·아이디어스와 다른 채널의 쓰기 권한 확대
- 가격·할인·재고·판매상태·광고·정산·계정 변경
- 고객 발송, 리뷰 조작, 계정 생성, 결제·환불·계약
- 사람이 지정하지 않은 채널·상품으로의 자동 확장

## 결과와 Trade-off

- 첫 쿠팡 등록 검증 뒤에는 대표가 상품마다 등록을 중계하지 않아도 된다.
- 기존 판매 상품의 문구 변경은 계속 건별 승인이라 검색·고객 인식 리스크를 통제한다.
- 실패·반려 1건에서 자동을 멈추므로 단기 속도보다 잘못된 대량 확산 방지가 우선된다.

## 전환과 검증

1. Claude Code가 카탈로그·쿠팡 쓰기 Adapter에 검사 Gate, idempotency, rollback과 실행
   기록을 함께 구현한다.
2. 비공개·임시 상품 또는 안전한 검증 범위에서 첫 1건의 등록·수정·rollback을 확인한다.
3. 대표 승인으로 채널별 첫 `L1` 상품을 실행하고, 외부 상품 ID와 결과를 보고한다.
4. 성공 기준은 Permit 없는 외부 쓰기 0건, 표현 검수 미통과 반영 0건, 중복 등록 0건,
   실행 기록·rollback 경로 100%다.

## 재검토 조건

- 쿠팡 또는 카탈로그 API 정책·권한·인증 방식 변경
- 오등록, 중복 등록, 표현 반려 또는 rollback 실패
- 스마트스토어·아이디어스 등 다른 채널로 쓰기 범위를 확대하려는 경우
- 가격 자동 조정을 검토하는 경우
